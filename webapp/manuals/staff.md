# BEST社員向け操作マニュアル（目標・稼働工数設定）

対象：BEST社員
最終更新：2026-11-05（Ver 1.447 時点）

## この画面でできること

目標・工数 →「目標・稼働工数設定」は、半期（6か月）ごとに、あなたの**稼働工数（％）**と**記事目標**を入力する画面です。

- 月ごとに、どの担当（メディア・ディレクトリなど）に何％の時間を使ったかを入力・保存する
- 保存済みの月の稼働工数を直したいときに、修正を申請する
- 担当メディアの記事目標（新規／リライト）を入力し、管理者に申請する
- 表示する半期を切り替える

> 表示されるのは、あなたに紐づく内容だけです。BEST社員管理に登録されていないと「あなたのアカウントは BEST社員管理に登録されていません。」と出ます。

稼働工数は支出の「BEST人件費」をメディアに分けるのに使われ、承認された記事目標は記事目標設定に反映されます。

## 画面の見方

### 半期の切り替え

「半期」のプルダウンで、次の半期・今の半期・前の半期から選べます（はじめは今の半期）。上期は5月〜10月、下期は11月〜翌年4月です。

### 稼働工数（％）の表

| 部分 | 意味 |
|---|---|
| 担当 | メディア・ディレクトリや、プレスリリース・PM・報酬サポートなどの担当 |
| 月の列 | その月に使った割合（％） |
| 合計 | 月ごとの合計。**100％にする必要があります**（100％でないと赤くなります） |
| 🔒 | 保存済みの月。本人は直接変えられません |
| 修正申請中・修正却下 | 修正の申請の状態（マウスを乗せると理由が出ます） |
| ＋ 項目を追加 | 行（担当）を増やします |
| × | その行を消します（保存済みの月は申請のときだけ） |

### 記事目標の表

| 部分 | 意味 |
|---|---|
| 担当 | 記事目標を立てるメディア・ディレクトリ |
| 新規・リライト | 月ごとの目標本数 |
| 状態 | 未入力・未申請・承認待ち・承認済み・却下 |

承認済みの値と違う数字を入れている欄は、マウスを乗せると「承認済み：〇」と出ます。Eparkくらしのレスキューの担当がある方は、半期の目標を文章で入れる欄も出ます。

## よくある操作

### 稼働工数を入力して保存する

1. 必要なら「＋ 項目を追加」で担当の行を足します。
2. 月ごとに、各担当の％を入れます。合計が100％になるようにします。
3. 「稼働工数を保存」を押します。「保存されました」と出れば完了です。

合計が100％でない月があると「保存できません。稼働工数は月ごとに合計100%にしてください」と出ます。何も入れていない月は確認しません。

### 保存済みの月を直す（修正の申請）

1. 「修正を申請」を押します。
2. 🔒 の月の数字を直します（月ごとに合計100％）。
3. 「修正の理由（必須）」を入れて「修正を申請する」を押します。
4. 管理者が承認すると変わります。やめるときは「やめる」を押します。

申請中に取り消したいときは「修正申請を取り下げる」を押します。却下されたときは、理由が赤字で出ます。

### 記事目標を入力して申請する

1. 担当ごと・月ごとに、新規とリライトの目標本数を入れます。
2. 途中で残すときは「記事目標を下書き保存」を押します。
3. 決まったら「記事目標を申請する」を押し、確認で OK を押します。
4. 管理者が承認すると、記事目標設定に反映されます。

## 注意・よくある質問

- **稼働工数は保存した時点で使われます。** 承認は不要ですが、一度保存した月は本人では変えられず、修正には申請が必要です。
- **記事目標は申請中（承認待ち）は変更できません。** 管理者が承認か却下をするまで待ってください。却下されたときは「却下の理由」が出るので、直してもう一度申請します。
- 担当の行が出ないときは、メディア担当管理で担当が登録されているか管理者に確認してください。
- マイページ（基本情報）には稼働％や記事目標は出ません。入力・申請はこの画面で行います。
