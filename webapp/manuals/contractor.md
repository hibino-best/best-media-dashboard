# 業務委託の方向け操作マニュアル（報酬・請求）

対象：業務委託の方（ディレクター・ライター・監修者）
最終更新：2026-11-05（Ver 1.447 時点）

## この画面でできること

報酬管理 →「報酬」は、あなた自身の報酬と請求を確認・操作する画面です。

- 月ごとの担当記事の本数・文字数・報酬額（税抜き）を見る
- 請求書を作って請求する、請求の状態を確かめる
- 請求書を見る・PDF をダウンロード・印刷する
- 稼働表（日ごとの作業時間）を入力する（時間単価の契約の方だけ）

> 見られるのは、あなたのメールアドレスで登録された契約の分だけです。契約が見つからないときは「あなたのメールアドレスの契約が見つかりません。管理者にお問い合わせください。」と出ます。

## 画面の見方

### 上：請求

| 列 | 意味 |
|---|---|
| 月 | 「〇年〇月分」 |
| 請求の期間 | その月の3日〜翌月2日 |
| 状態 | 未請求・請求確認中・差し戻し・経理部確認中・請求完了 |
| 請求金額 | 税込みで、源泉所得税を引いた後の金額 |
| 操作 | 「請求書を作成」「直して出し直す」「請求書を見る・PDF」 |

状態の意味は次のとおりです。

| 状態 | 意味 |
|---|---|
| 請求確認中 | BEST の請求担当が内容を確認しています |
| 差し戻し | 直してほしいところがあります（理由が下に赤字で出ます） |
| 経理部確認中 | 請求担当の確認が終わり、経理部が確認しています |
| 請求完了 | 請求の手続きが終わりました |

### 下：報酬

| 部分 | 意味 |
|---|---|
| 対象月 | 今月と過去11か月から選べます。今月は「（途中）」 |
| 数字のカード | 新規記事・リライト・文字数・画像・アップロード・監修などの本数や量と、報酬額（税抜き）。契約に単価がある項目だけ出ます |
| 契約内容 | あなたの契約の単価 |
| 記事の表 | アップロード日・メディア・検索KW・記事タイトル・種類・担当・文字数（画像） |

担当記事は、その月に完了した（アップロード日が入った）記事のうち、あなたが担当（ディレクション・執筆・アップロード・監修）の記事です。報酬額は契約内容の単価×本数などで計算した税抜きの金額です。構成の単価がある方は「合計」「構成担当」「構成未担当」で表を切り替えられます。

## よくある操作

### 請求書を作って請求する

1. 請求の表で、その月の「請求書を作成」を押します。
2. 「請求の内容」は報酬の計算から自動で入ります（直せません）。足りない記事があるときは、先に進行管理を直してもらってから請求してください。
3. BEST と事前にすり合わせた項目があるときだけ「＋ その他の項目を追加」で内容・数量・単価を入れます。使わない行は × で消します。
4. 「請求者の住所」を入れます（郵便番号・都道府県・市区町村・丁目・番地は必須）。郵便番号を7けた入れると、都道府県と市区町村が自動で入ります。
5. 「お振込先」を入れます（銀行名・支店名・種別・口座番号・口座名義（カナ）は必須）。前の月に請求していれば「〇年〇月分からコピー」が使えます。
6. 「確認へ」を押し、「内容にお間違いはないですか？」の画面で確かめます。直すときは「戻って直す」。
7. 「請求する」を押すと「請求しました。請求担当の確認をお待ちください」と出ます。

請求書には、小計（税抜き）・消費税10%・（個人の方は）源泉所得税・ご請求金額が載ります。

### 差し戻されたとき

1. 請求の表の赤字で、差し戻しの理由を確認します。
2. 「直して出し直す」を押して直し、もう一度請求します。

### 請求書を見る・保存する

「請求書を見る・PDF」を押すと請求書と記録が出ます。「PDF をダウンロード」か「印刷」で保存できます（2026年11月分から）。

### 稼働表を入力する（時間単価の契約の方だけ）

報酬の下に「稼働表」が出る方は、日ごとに時間を入れます。

1. 日ごとに「予定時間」「予定内容」、ライター業務（ライティング・画像作成・アップロード・リライト）、ディレクター業務（1.ミーティング〜6.ナレッジ共有）、「詳細」を入れます。
2. 時間は15分単位です（15分＝0.25・30分＝0.5・45分＝0.75・60分＝1）。
3. 「稼働表を保存」を押します。「稼働表を保存しました」と出れば完了です。

報酬額＝ディレクター業務の時間×時間単価です。ライター業務の時間は記録用で、報酬は文字数・枚数・本数の単価で別に計算します。

## 注意・よくある質問

- **請求は1か月に1回です。** その月の3日〜翌月2日に請求してください。翌月3日・4日は「期日を過ぎた理由」を入れれば受け付け、5日以降は受け付けません。
- 請求したあとに完了した記事は、翌月分の請求に入ります。
- この画面での請求は 2026年11月分からが対象です。
- 稼働表は、前月分は毎月2日まで、次月の稼働予定は毎月20日までに入力してください。
- 報酬はアップロード日の月で数えます。記事の数や文字数が違うときは、進行管理の内容をディレクション担当に確かめてもらってください。
- 「契約管理で『個人／企業』が入っていません」と出たら、BEST に連絡してください。
