# ライター向け操作マニュアル（月次進行管理）

対象：ライター（業務委託ライター・契約外ライター）
最終更新：2026-11-13（Ver 1.567 時点）

## この画面でできること

コンテンツ作成 →「月次進行管理」は、**あなたに割り振られた記事**を月ごとに確認し、書いた原稿のURLや文字数などを入力する画面です。

- 月ごと（アップロード目標月ごと）に、割り振られた記事の一覧を見る
- 構成（記事の設計図）を開いて確認する
- ライティングURL・文字数・コピペ率（CCD）・画像枚数・進行状況・アップロードURL・アップロード日を入力する

> ライターの方がコンテンツ作成で見られるのは、この「月次進行管理」だけです。

ここで入れた内容は、そのままコンテンツ進行管理と、報酬・請求の計算に使われます。

## 画面の見方

### 月の切り替え

| ボタン | 意味 |
|---|---|
| ◀ 前の月 | 1か月前を表示します |
| 次の月 ▶ | 1か月先を表示します |
| 今月 | 今月に戻ります（今月以外を見ているときだけ出ます） |

表示される記事は、ディレクション担当が決めた「アップロード目標月」がその月の記事です。目標月がない記事は、アップロード日がその月の記事が出ます。その月に記事がないときは「〇年〇月にアップロード目標の記事はありません。」と出ます。

### いちばん上の集計表

| 列 | 意味 |
|---|---|
| 割り振り | その月に割り振られた記事の本数 |
| 執筆完了 | 進行状況が「記事執筆完了」より先まで進んだ本数 |
| アップロード済み | アップロード日が入っていて、その日を過ぎた本数 |

### 記事の表

| 列 | 意味 | 入力 |
|---|---|---|
| メディア | どのメディアの記事か（ディレクトリがあれば下に小さく表示） | できない |
| No. | 記事の番号 | できない |
| 検索KW | 記事で狙う検索キーワード | できない |
| 制作判断 | 新規・リライトなどの種類 | できない |
| 依頼日 | 記事を依頼した日 | できない |
| アップロード目標月 | アップロードの目標の月 | できない |
| 進行状況 | 記事がどこまで進んだか | **できる**（選ぶ） |
| 構成URL | 「構成を開く」で構成を見られます | できない（見るだけ） |
| ライティングURL | 原稿（Google ドキュメント）のURL。入れると「開く」が出ます | **できる** |
| 文字数 | 原稿の文字数 | **できる** |
| コピペ率（CCD） | CCD（ccd.cloud）でチェックした結果の% | **できる**（ボタンを押して入力） |
| 画像枚数 | 作った画像の枚数 | **できる** |
| アップロードURL | 公開した記事のURL | **できる** |
| アップロード日 | 記事を公開した日 | **できる** |

**ライターが直せるのは、ライティングURL・文字数・コピペ率（CCD）・画像枚数・進行状況・アップロードURL・アップロード日だけです。** それ以外の項目（担当者・目標月など）は、ディレクション担当に連絡してください。

## よくある操作

### 原稿のURLを入れる

1. 記事の行の「ライティングURL」の欄に、Google ドキュメントのURL（https://docs.google.com/… で始まるもの）を貼り付けます。
2. 欄の外をクリックするか Enter を押すと、すぐに保存され「保存しました」と出ます。
3. 原稿を読み取れると、文字数（スペースを除く）が自動で入り「文字数（スペースを除く）を 〇文字 にしました」と出ます。

> 文字数を自動で入れるには、原稿の Google ドキュメント（またはフォルダ）を、ダッシュボード用のアカウント（dashboard-app@ で始まるアドレス。読めないときのメッセージに表示されます）に「閲覧者」で共有しておく必要があります。

文字単価の契約の方には、「請求対象外の文字は含まれていませんか？」という確認が出ます。アフィリエイトリンク・内部リンク・HTMLコードが文字数に入っていないか確かめてください。自動で入った文字数は、文字数の欄で直せます。

### コピペ率（CCD）を入れる

1. 原稿を CCD（https://ccd.cloud/）でチェックします。長い原稿は何回かに分けてチェックしてください。
2. 記事の行の「コピペ率（CCD）」の「入力」ボタンを押します。
3. 結果の%を入れます。分けてチェックしたときは「＋ 行を追加」で、分けた数だけ入れます。平均が自動で出ます。
4. 「保存」を押すと保存され、ボタンに「平均35%（3）」のように表示されます。もう一度押すと直せます。

### 進行状況を変える

1. 「進行状況」のプルダウンを開き、今の段階を選びます。
2. 選んだ時点で保存されます。

進めるのに必要な項目が足りないと、「『〇〇』にできません」という画面が出て、足りない項目（例：ライティングURLが入力されていません）が表示されます。

- 「記事執筆完了」より先にするには、ライティングURLが必要です。
- 「完了」にするには、コピペ率（CCD）も必要です。自動のコピペチェック（簡易）は参考程度なので、原稿は必ず CCD でチェックしてください。
- 進行状況を「記事執筆完了」以降にすると、ライティングURLのドキュメントから文字数が自動で入ります。文字数の欄の下の「取得」（文字数が入っているときは「再取得」）ボタンを押すと、いつでも今の文字数を数え直せます（ドキュメントを dashboard-app@bestmedia-510909.iam.gserviceaccount.com に「閲覧者」で共有しておく必要があります）。
- 「構成作成完了」より先や「完了」には、担当者・構成URLなど、ディレクション担当が入れる項目も必要です。足りない項目がライターの直せない項目のときは、ディレクション担当に入力をお願いしてください。

### 公開したら

1. 「アップロードURL」に公開した記事のURL（http:// か https:// で始まるもの）を入れます。
2. 「アップロード日」に公開した日を入れます。

## 注意・よくある質問

- **入力するとすぐ保存されます。** 保存ボタンはありません。保存できなかったときは「保存できませんでした：〜」と出て、元の値に戻ります。
- 「URLを保存できません」と出たら、ライティングURLは https://docs.google.com/… 、アップロードURLは http:// か https:// で始まっているか確かめてください。
- **報酬・請求は、実際のアップロード日の月で数えます。** 目標月とアップロード日の月がずれた記事は、アップロード日の月の報酬に入ります。
- 割り振られているはずの記事が出ないときは、月を切り替えて確かめてください。それでも出ないときは、執筆担当やアップロード目標月が入っていない可能性があるので、ディレクション担当に連絡してください。
- 入力した内容は、ディレクション担当が見るコンテンツ進行管理と同じデータです。
