# ディレクション担当向け操作マニュアル（コンテンツ進行管理）

対象：ディレクション担当（社員・業務委託のPM／ディレクター／AD／アシスタント兼ライター）
最終更新：2026-11-13（Ver 1.567 時点）

## この画面でできること

コンテンツ作成 →「コンテンツ進行管理」は、記事ごとの進み具合・担当者・URLなどを一覧のまま入力・管理する画面です。

- 新しい記事のKW（キーワード）を追加する（新規・リライト・簡易リライト）
- 進行状況・担当者・アップロード目標月などをプルダウンや手入力で変える
- 見出しを押して並び替える、条件で絞り込む
- チェックした記事をまとめて変える・削除する（一括操作の権限がある人だけ）
- 画面の下で、選んでいるメディアのプレスリリースを見る

> 変更するとすぐに保存され、記事一覧に反映されます。スプレッドシートには書き込みません。ここで変えた項目は、シートを取り込み直してもダッシュボードの値が優先されます。

## 画面の見方

### 上のボタン・絞り込み

| 部分 | 意味 |
|---|---|
| 進行状況・制作判断・監修有無・各担当の絞り込み | 「すべて」から条件を選んで表示をしぼります。進行状況は「完了以外」も選べます |
| キーワード | タイトル・KW・No.・URLで検索します |
| ＋ 新規KW追加 | 新しい記事の行を追加します |
| ＋ リライトKW追加 | 過去に新規で作った記事と同じKWをリライトするときに使います |
| ＋ 簡易リライトKW追加 | 過去の記事と同じKWを簡易リライトするときに使います |
| さらに100件表示 | 100件ずつ表示を増やします |

メディアは画面の右上で選びます。「メディア累計」のときはKWを追加できません。

### 主な列

| 列 | 意味 |
|---|---|
| No.・検索KW | 記事の番号とKW。新規の記事は No. が必須です |
| 検索Vol | Ahrefs の直近12か月の平均検索数（自動。入力・修正はできません。* はまだ取得していないKWで、シートの値） |
| 進行状況 | 未着手 → 構成作成中 → … → 完了 |
| 制作判断 | 新規・リライト(新規)・リライト・簡易リライト |
| 緊急性・ターゲット層・クエリタイプ・ポジション | 選ぶ項目 |
| 監修有無 | 監修者ありのメディアだけ表示 |
| 依頼日・アップロード日 | 日付 |
| ディレクション担当・執筆担当・アップロード担当・監修担当 | 契約中の人から選びます |
| アップロード目標月 | その記事をアップロードする予定の月（執筆担当の右） |
| カテゴリ・タグ・CTA・訴求ブロック | 公開済みの記事は WordPress の値を表示します |
| 構成URL・ライティングURL | Google スプレッドシートか Google ドキュメントのURL |
| コピペ（簡易）・コピペ | 自動のコピペチェックの結果（参考程度。原稿は必ず CCD でチェックし「コピペ率（CCD）」に記録） |
| 文字数・画像制作枚数・記事URL・記事タイトル・メモ | 記事の情報 |

列の見出しを押すと並び替えます（押すたびに 昇順 ▲ → 降順 ▼ → 元の並び）。空欄はいつも下になります。コピペ・タグの列は並び替えできません。

## よくある操作

### 新しい記事を追加する

1. 右上でメディアを選びます。
2. 「＋ 新規KW追加」を押すと、表のいちばん上に行が出ます。
3. **No. と検索KWを入れると保存されます**（No. は必須です）。

### リライトの記事を追加する

1. 「＋ リライトKW追加」か「＋ 簡易リライトKW追加」を押します。
2. 検索KWに、過去に新規で作った記事と**完全に同じ表記**のKWを入れます（スペースの位置なども同じ）。
3. No.・検索Vol・記事URLは元の記事から自動で入ります。同じKWが見つからないときは保存できません。

### 執筆担当とアップロード目標月を入れる

1. 執筆担当を選びます。
2. **執筆担当を入れたら、アップロード目標月も必須です。** 目標月の欄が赤い枠になるので、月を選ぶと2つまとめて保存されます。
3. 目標月を入れると、ライターの「月次進行管理」のその月に記事が出ます。

執筆担当が入っている記事は、アップロード目標月を空にできません。

### 進行状況を進める

段階ごとに必要な項目が入っていないと、「『〇〇』にできません」と足りない項目が出ます。

| 進行状況 | 必要な項目 |
|---|---|
| 構成作成完了 より先 | 担当者全員・構成URL・緊急性・ターゲット層・クエリタイプ・ポジション |
| 記事執筆完了 より先 | 上に加えてライティングURL |
| 完了 | コピペ率（CCD）・No.・検索KW・制作判断・依頼日・アップロード日・アップロード目標月・文字数・画像制作枚数・記事URL など |

### まとめて変える（一括操作）

1. 行の左のチェックボックスで記事を選びます（見出しのチェックで表示中をすべて選択）。
2. 出てきたバーで「一括操作を選ぶ」から「〇〇を変更」か「KWを削除」を選びます。
3. 値を選んで「適用」を押します。「選択を解除」で選択をやめます。

進行状況をまとめて変えるとき、足りない項目がある記事は変わらず、理由が一覧で出ます。

### 行を削除する

行の右の「削除」を押し、「もう一度押すと削除」をもう一度押します。削除できるのは、この画面で追加した行だけです。

## プレスリリースの表示

表の下に、選んでいるメディアのプレスリリースが「進行中」「公開済み」に分かれて出ます。ここでは**見るだけ**です。入力・追加は コンテンツ作成 →「プレスリリース進行管理」で行います（編集できるのは社員だけ。業務委託のディレクション担当は見るだけです）。

## 注意・よくある質問

- 記事URL・ライティングURLを入れると、コピペチェック（簡易）が自動で始まります（20〜40秒ほど）。結果は参考程度なので、原稿は必ず CCD でチェックし「コピペ率（CCD）」に記録してください。
- ライティングURLに Google ドキュメントを入れると、文字数が自動で入ります。原稿をダッシュボード用のアカウントに「閲覧者」で共有していないと読めません。
- 上に「WordPressで公開された新規記事が、進行管理より多くなっています」と出たら、記事管理シート（アップロード日・制作判断）を更新してください。
- 「自分が担当の記事だけ修正できます」と出た場合は、担当の記事だけを直せる権限です。
- 担当者のプルダウンで「（担当外）」「（未登録）」と付く名前は、そのメディアの契約にいない人です。
