# 引き継ぎフォルダ

BESTのチームアカウントの Claude Code で、この「BESTメディア月次集計」の作業を続けるためのものです（2026-10-13 作成）。

## 使い方
1. チームアカウントで Claude Code（デスクトップアプリの Code タブ）にログインする。
2. フォルダに「BESTメディア月次集計」を選んで新しい会話を始める。
   - 一つ上の `CLAUDE.md`（引き継ぎ書）が自動で読み込まれ、これまでと同じ手順・ルールで作業できます。
3. 過去のやりとりを確認したいときは、`会話の記録/会話の記録_BESTメディア月次集計.md` を開く（Claude に「会話の記録を読んで」と頼むこともできます）。

## 中身
| ファイル | 内容 |
|---|---|
| `会話の記録/会話の記録_BESTメディア月次集計.md` | これまでの会話（ユーザーとClaudeのやりとりの本文、約700件）。読む用 |
| `会話の記録/会話の記録_全データ.zip` | 会話の完全な書き出し（ツールの実行結果を含む）。保管用 |
| `会話の記録/会話の記録_元データ.jsonl` | Claude Code の会話の元ファイル。保管用 |
| `記憶/` | Claude の作業メモ（記憶）の写し。同じPCの同じWindowsユーザーなら、元の記憶もそのまま読み込まれます |

## 注意
- 元の会話そのもの（続きから話せる状態）は、別のClaudeアカウントには移せません。上の記録と `CLAUDE.md` で引き継ぎます。
- 会話の記録には、システムの設定値（スプレッドシートのID、GCPのプロジェクト名など）が含まれます。APIキーやパスワードは含まれていません（ログイン用の一時コードは期限切れ。読む用のファイルでは削除済み）。社外には共有しないでください。
- 別のPCで使う場合は、このフォルダごとコピーし、clasp と gcloud にチームアカウントでログインし直してください（GCP・GAS・GA4・Search Console・スプレッドシートの権限がチームアカウントにあることが前提）。
